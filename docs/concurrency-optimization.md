# 并发与吞吐优化

本轮基于已有雪花 ID 和独立本机日志改造，覆盖 P0、P1、P2。它不包含生产负载压测结果。

| 路径 | 行为 |
| --- | --- |
| MySQL 邮箱写入 | 使用 ReadCommitted，按 ID 顺序锁相关 mailbox 行。标记、同账号移动不再锁域配额行；入站与 Sent 操作为目标账号预锁已有文件夹，涵盖规则转发和 Sent 去重。账号、域配额在保存末尾用条件增减更新，超限时整个业务事务回滚。维护、重算与删除仍保留范围锁。 |
| SQLite 写入 | 保留 Serializable，因为 SQLite 不提供 MySQL 式 ReadCommitted 行级锁。 |
| IMAP 计数与 UID | MessageCount、UnseenCount 在同一事务内随新增、Flags、移动、软删除、恢复和删除变化。正常 UID 分配不再查询历史最高 UID；导入写入、迁移和显式修复维护 UIDNEXT 单调性。 |
| IMAP FETCH | 从已授权选择中的 ContentKey 直接读取内容。ENVELOPE、BODY、BODYSTRUCTURE 和头/正文偏移首次访问后持久化，进程内缓存有界，按消息和解析版本识别；单条元数据超过512KiB时不持久化、不缓存。 |
| TLS | 复用 SslStreamCertificateContext，后台检查配置和文件变化。暖态握手无需数据库或文件读取；初次加载或本进程收到配置失效仍可等待刷新。旧上下文保留10分钟供进行中的握手使用。 |
| 外发批处理 | 同一轮租约内按消息、信封发件人、收件域、路由、转发规则和深度聚合。通过插件的成员共享 MIME 准备、DKIM 签名和一次 DATA，RCPT 结果、租约、完成和退信独立处理。跨轮租约或不同转发信息不合并。 |
| 外发缓存 | DKIM 签名器按域、选择器、路径、修改时间和长度缓存，并串行使用同一实例。连接池每 Key 可保留多个独占租用的客户端；连接销毁在锁外执行。MTA-STS 按到期时间和复查间隔缓存。 |
| 临时存储 | 快照在64KiB且1024条以内使用内存，超限溢写临时文件；小 Literal 使用可归还的池化内存。FETCH 每条完整响应统一刷新，大正文分块发送并归还数组；EHLO 能力列表合并发送。 |
| 内容去重 | 并发相同内容落盘允许目标文件已存在。保存/复用刷新文件时间；最近5分钟写入的无引用内容不立即删除，后续由孤儿扫描回收。保护期用于覆盖尚未提交的写入；异常长事务应通过超时与运维处理。 |
| 后台写入 | 本机审计/投递尝试进入有界批写队列，并等待结果；TLS 报告事件最多每5秒批写256条，关闭时排空。TLS 遥测失败不会把已成功的 SMTP DATA 改判为失败。队列不是持久化 outbox，进程崩溃可能丢失尚未落盘的遥测。 |
| 雪花 ID | 持久化预留10秒时间窗，剩余30%时后台续约；fsync 在分配锁外执行，仅冷启动或窗口耗尽时等待，未持久化的时间戳不会用于发号。重启与时钟限制见[雪花 ID 与本机日志](local-logs-and-snowflake-ids.md)。 |
| CPU 与同步 | 密码成功结果缓存90秒，键包含当前密码哈希与进程 HMAC，PBKDF2 并发受 CPU 数限制；账号启停仍查库。防火墙使用单 IP 哈希表和压缩前缀树；连接保护通过可淘汰链表移除最旧空闲项。SQL 模板指纹按模型有界缓存。邮箱异步锁按实际 Key 租借并回收。 |
| 同机多进程 | 命名管道广播投递和邮箱提交提示，50毫秒合并；数据库租约、轮询和 IMAP IDLE 定时刷新仍是恢复机制。 |

## 部署与迁移

新增 SQLite/MySQL `MailboxCountersAndFetchMetadata` 迁移。停写后执行原有 `mailserver db update` 流程，再启动全部新版本角色，避免旧版本继续写入时不维护新计数。迁移会初始化已有文件夹计数和 UIDNEXT，耗时随邮件量增长；执行前备份数据库。GUID 旧链仍不能直接升级到雪花 ID 链。

MailboxMessage、DeliveryJob、SentCopyJob 的 MessageId 单列索引现在在模型中显式声明；现有迁移已由 EF 外键约定创建这些索引，因此新迁移不重复创建。

原有 `SmtpConnectionReuse.Enabled=false` 默认值保持不变。启用连接复用时，旧配置中的全局上限4会继续生效；可按实际外发并发配置全局和每 Key 上限，参见[配置说明](configuration.md)。
