## Vue/Vuetify 管理后台

`/admin` 提供：

- 仪表盘和健康概览；
- 域名、Direct MX 就绪性和 DKIM 配置；
- 邮箱账号、密码、状态和配额；
- 绑定同域账号的收发信别名；
- 域名级收信和发信文件夹规则；
- API Key 创建与撤销；
- 投递队列查询、重试与删除；
- MX、SPF、DKIM、DMARC 诊断；
- 系统设置中调整投递批量、租约、最大重试次数、轮询间隔和 IMAP 默认文件夹；
- 管理员密码修改。

管理端是独立 Vue 3 SPA，只通过 `/api/v1` JSON 契约访问服务端。浏览器使用 HttpOnly、SameSite Cookie 与 CSRF header；外部 API 保留 JWT 与 `X-Api-Key`。

## 集群升级与架构兼容

集群协议会交换复制架构指纹。主节点和子节点的数据库/复制模型不一致时，节点不能加入，
运行中的连接也会被拒绝；邀请令牌不会因为架构不匹配而被消耗。不同数据库提供程序
（SQLite、PostgreSQL、MySQL）只要使用相同 MailServer 模型，就会生成相同指纹。

涉及数据库架构变化的版本不支持在线滚动升级。升级步骤：

1. 进入维护窗口，停止业务写入和集群复制。
2. 在所有节点安装同一版本。
3. 在每个节点分别执行 `mailserver db update`。
4. 确认所有节点启动检查通过后，再恢复集群服务和业务写入。

如果子节点已经因架构不一致发生部分同步，升级迁移后应执行完整重新同步；无法确认数据
完整性时，应先在主节点移除该节点，再清空子节点的应用数据库和邮件存储并重新加入。
关闭集群只清理当前服务器上的集群身份、证书和复制状态，不删除邮件、账号、域名等业务数据，
也不会联系、关闭或擦除其他服务器。用户输入完整集群名称后，当前服务器可以直接退出集群，
不要求其他节点在线，也不检查它们的状态。

## 只读主节点紧急恢复

见证节点或备节点失联后，主节点会在租约失效时进入只读状态。普通业务写操作仍会返回
`503`，但集群管理页、管理 API 和本机 CLI 允许逐个强制移除失联子节点。第一次强制移除
会把 `Cluster:RecoveryRequired` 持久化为 `true`；因此重启服务器不会绕过恢复锁。

强制移除只修改当前主节点的本地状态，远端服务器仍可能继续运行。应先在网络或基础设施层
将旧备节点和见证节点关机、断网或隔离，否则可能出现多个主节点同时写入并造成数据冲突。

1. 在主节点逐个强制移除失联的备节点和见证节点。
2. 仍有子节点时主节点继续只读；最后一个子节点被移除后，系统会清空失效见证地址、递增
   主租约任期并自动恢复写入。
3. 被移除的服务器必须清空应用数据库和邮件存储后才能重新加入，不能直接重新联网。

后台不可用时，可在主节点本机执行
`mailserver cluster force-remove --node-id <节点ID或唯一名称>`。该命令不会联系或擦除远端服务器。

如果需要让当前服务器直接退出集群并恢复单机配置，可在主节点、备节点或见证节点执行：

`mailserver cluster force-leave --confirm-name <集群名称>`

该命令不依赖管理后台和远端服务器。它会清理当前服务器的集群状态和证书、关闭集群端口，
同时保留本机业务数据。其他服务器必须由管理员分别关闭、清理或重新初始化。
